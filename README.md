# 🎶 Music Mania - Landing Page

Welcome to **Music Mania** — a beautifully crafted landing page for a music learning organization. This project blends aesthetic design and modern web technologies to create a visually stunning and responsive user experience.

## ✨ Project Aim

The goal of this project is to build a **visually striking and pixel-perfect landing page** for a music teaching organization that reflects creativity, professionalism, and passion for music.

## 🔗 Live Demo

🌐 [Visit Music Mania](https://music-mania-koustav.vercel.app)

## 🛠 Tech Stack

This landing page is built using the following technologies:

- ⚡ **Next.js 14** – App Router for lightning-fast performance and seamless routing.
- 🎨 **Tailwind CSS** – Utility-first CSS framework for rapid UI development.
- 🪄 **Aceternity UI** – Beautiful UI components to enhance design and interactivity.

## 🚀 Features

- Fully responsive design (Mobile-first)
- Smooth animations and transitions
- Reusable and clean component structure
- Fast load times and optimized performance
- Elegant typography and visual hierarchy

## 📦 Installation & Development

To run this project locally:

```bash
# 1. Clone the repository
git clone https://github.com/koustavFF/music-mania.git
cd music-mania

# 2. Install dependencies
npm install

# 3. Run the development server
npm run dev

# 4. Open your browser
Visit http://localhost:3000
````

Make sure you have **Node.js** and **npm** installed on your system.
